# The Best Auto Refresh App — documentation

The Best Auto Refresh App is a free, open-source Chrome and Chromium extension
that refreshes a tab until the thing you care about happens. It has no account,
ads, analytics, or paywalls, and monitoring runs on your device.

This site hosts the project's published documentation.

- [Privacy policy](PRIVACY.html) — what the extension stores, sends, and never collects.
- [Chrome Web Store submission guide](SUBMISSION.html) — registration, listing, and automated releases.
- [Store listing preparation](STORE.html) — draft listing copy and permission justifications.
- [Automation guide](AUTOMATION.html) — optional webhooks and custom scripts.
- [Validation notes](VALIDATION.html) — how the extension is tested.
- [Icon notes](ICON.html) — icon sources and generation.
