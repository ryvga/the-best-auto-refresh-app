## Draft listing

Name: The Best Auto Refresh App

Short description: Refresh tabs on a timer or until page content, keywords, or selected elements change. Free, local, and open source.

Description:
Refresh smarter. Stop when it matters.

Choose a steady interval or randomize the delay. Watch the whole page or a selected element, and stop when text changes, a keyword appears or disappears, or an element appears or disappears. Save settings for a page, website, or general use and switch profiles from the popup. See the countdown on the toolbar. Pause, resume, and manage monitored tabs in one dashboard.

Optional automation sends webhooks or runs your custom JavaScript on selected monitoring events. Webhooks request access to the configured hostname, and scripts require Chrome's optional User Scripts permission, site access, and Allow User Scripts setting. These features are off by default. Activity logs show hook outcomes; access can be revoked from the dashboard.

Use guided ntfy setup and send a test notification before watching a page. Optional pause-on-interaction protects your workflow while clicking or typing. Settings remain independent per tab; reuse them explicitly through saved profiles. Starting a tab never silently changes shared defaults or enables automation on another tab.

All features are free. No account, ads, subscriptions, analytics, or developer data collection. Monitoring runs on your device. Optional webhooks send the data you configure to your chosen endpoint; page details are excluded by default.

A voluntary Support development link opens the developer's Ko-fi page. Supporting development is optional and does not unlock features. No payment code or tracking pixels are embedded in the extension.

Timing may be delayed in background tabs or while the computer sleeps. Browser-internal pages and protected browser pages cannot be monitored.

## Single purpose

User-controlled page refreshing with local content conditions that determine when refreshing stops. Profiles, the picker, the dashboard, and event automation support this same purpose. Custom scripts execute only through the documented User Scripts API; no remote code is executed in extension contexts.

## Permission justifications

activeTab: User-triggered access to the selected page for refresh and monitoring; avoids broad site access.
scripting: Inject bundled monitoring/picker code into the selected page.
storage: Persist preferences and temporary per-tab monitoring state.
alarms: Wake the service worker for scheduling and watchdog checks.

Optional userScripts: Execute user-authored code for selected monitoring events in the isolated USER_SCRIPT context. Only after the user enables the feature and browser setting. No dynamic registration across unrelated pages.
Optional host access: Connect user-configured HTTPS webhook endpoints or script websites, and loopback HTTP endpoints for local development. Request a specific host from an explicit user gesture; never request all optional hosts in one call. Disclose that Chrome host grants cover paths/ports on that hostname.

## Submission checklist

- Publish the repository privacy policy at a stable accessible URL and enter it in the developer dashboard.
- Complete privacy disclosures accurately: no developer collection; user-directed webhook transmission and optional script execution must be disclosed. Describe payload fields and opt-in page details.
- Upload the ZIP generated by scripts/package.ps1, not the whole repository.
- Capture actual 1280x800 or 640x400 screenshots showing popup, stop conditions, and dashboard; use actual UI only.
- Review icon and manifest version; test installation from the ZIP contents.
- Confirm current Chrome policies and registration requirements at submission time.
- Include review instructions and a controlled example for optional webhooks and User Scripts, including the Chrome 138+ Allow User Scripts toggle. Verify permission revocation and unsupported/disabled API handling.
- Keep claims factual. No fake ratings, badges, rankings, or approval promises. The requested product name may require adjustment if Google flags promotional metadata.
- Register a developer account if required; registration fees are separate from offering the extension free to users.
